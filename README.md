# Internly v2

Internly v2 is a rebuild of my original internship portal for students and companies. It is a work in progress, so a lot of what is below is the plan rather than finished work.

The original version is here: [sjv24/internly](https://github.com/sjv24/internly)

## Why I'm rebuilding it

I built the first Internly with plain HTML, CSS and JavaScript on the frontend and Node.js with MySQL on the backend, with no frameworks. It works, and I learned a lot from it, but I also know where it falls short. A lot of the code is written the way a beginner writes it, and the stack is not what most teams use day to day.

This time I want to build it properly, with technologies that are more relevant in the industry, and use the project to strengthen my fundamentals instead of just getting something working.

## Planned tech stack

- Java for the backend
- TypeScript and React for the frontend

I may adjust this as I go, and I will update this section when the choices are final.

## How it should be better than v1

- A cleaner structure. The first version has large files that do too many things, and I want to split the code into smaller, clearer pieces.
- Type safety on the frontend with TypeScript, so more mistakes get caught before the app runs.
- A component based interface with React instead of separate hand-written HTML pages.
- Proper setup instructions, so anyone can clone the repo and run it without guessing.
- Features I did not get to in v1: internship recommendations based on a student's profile, notifications for new listings and deadlines, and analytics so companies can see how their applications are doing.

## Core features (same as v1)

Students can register, search and filter internships, apply, and track their applications.
Companies can register, post internships, manage their listings, and review applications.
